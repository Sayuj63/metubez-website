# MeTubez website

India's landscape-first video platform — marketing site.

Built with Next.js 16 (App Router) + Tailwind CSS 4 + Lato font. Deploys to Vercel.

## Pages

- `/` — Home
- `/metubers` — Creator program
- `/brands` — For Brands
- `/company` — Company (stub)

## Development

```bash
npm install
npm run dev       # http://localhost:3000
npm run build
npm run start
```

## Stack

- Next.js 16.3 (App Router, TypeScript)
- Tailwind CSS 4
- Lato (Google Fonts, self-hosted via `next/font`)
